# URC 2027 constraints mapped to software

Reviewed 2026-10-20 against the user-supplied **University Rover Challenge Rules 2027(3).pdf** and the [official Q&A](https://urc.marssociety.org/home/requirements-guidelines/qa), including its October 11 updates. The PDF is not redistributed here. Check the [official requirements page](https://urc.marssociety.org/home/requirements-guidelines) before release: Q&A updates are binding.

| Rule / clarification | Software implication | v0.1 |
|---|---|---|
| 1.e.i: 40 minutes, astronaut assistance + route finding, 50 points each | Two task executives, bounded execution times | Route demonstration only |
| 1.e.ii: red autonomy, blue teleop, flashing green arrival | State indicator output on rover, visible without C2 | LED-state topic; hardware not implemented |
| 1.e.iii / autonomy Q21 | Programming only while stopped; operators hands-off during autonomous motion | Fixed mission input; no runtime goal editor |
| 1.e.v / vi / ix | 3m astronaut approach/follow/come criteria | Not implemented |
| 1.e.vi / autonomy Q6 and Q11 | Full Follow command points for body gesture; fallback modes permitted; no finger/facial gestures | Not implemented |
| Autonomy Q7 / Q13 | Astronaut-originated commands; Follow→Stay→Fetch→Come→Give | Planned state machine |
| 1.e.xii / xv / xvi | Two hilly-area targets, including one behind a hill | Small Nav2 course exists; full terrain trial pending |
| 1.e.xiii | Approximate bounds (38.411 N, -110.786 longitude) to (38.425 N, -110.768 longitude); imagery/DEM encouraged | Catalog bbox and importer |
| Autonomy Q20 | Organizer DEM release and date are not guaranteed | Independent public-data pipeline |
| 1.e.xiv | Drone must land before rover leaves mission start for route-finding targets | No drone in this demo; future explicit takeoff/landing state interlock |
| 1.e.xvii / autonomy Q16 | Stop within 1m; exact target GNSS coordinates; ArUco 4x4_50 posts | Local demo arrival check 0.75m; real GNSS/marker performance not proven |
| Autonomy Q18 | Rover LED sufficient for the out-of-link target | Onboard arrival indication; no C2 acknowledgement dependency |
| 1.e.xviii | Penalty-bearing stop/retreat and restrictions on teleoperated retreat | Safe cancel exists; legal breadcrumb retreat not implemented |
| Rover Q5 | No satellite internet relay to robot; local relay allowed | Competition runtime designed offline |
| 1.a.ii | C2 setup within 15 minutes; teardown within 10 | Reproducible environment helps; deployment timing not tested |

Only the initial route-navigation subset is implemented. Do not assume a generic ROS navigation stack satisfies the astronaut tasks, hill traversal, penalties, timing or field safety requirements.
